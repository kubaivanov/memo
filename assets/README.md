# Brand assets

The Memo icon and banner. All files are finished vectors turned into paths — no
font or design tool is needed to use them, and nothing here depends on a
specific machine.

| File | Purpose |
| --- | --- |
| `logo.svg` | The icon, 128×128. Use anywhere a square mark is needed. |
| `logo-on-dark.svg` | The same icon for dark surfaces (blue plate, light lines). |
| `banner.png` / `banner.svg` | README header, 1280×280. SVG is the source, PNG the export. |
| `banner-on-dark.png` / `.svg` | The same header for dark mode, transparent background. |
| `social-preview.png` | GitHub social preview, 1280×640 — upload it in Settings → Social preview. |
| `demo.gif` | README demo, 1280×720: two new sessions, one with `memo memory wake`. |
| `logo-512.png` | Repository avatar (GitHub keeps avatars as an upload, not a file). |
| `logo-180.png`, `logo-32.png` | Apple touch icon and favicon, for docs pages or any site showing Memo. |

Do not redraw the mark by hand: the geometry and colours are fixed — plate
`#fbfcff` (icon `#edf2fe`), ink `#33303e`, accent `#1d4ed8`. Anything that needs
to move gets regenerated from the source, not edited here.
